# Audit — 16 Nov 2026

Source-level review of the implementation against the claims in `README.md`,
one day after the initial build. Recorded before any fixes, so the repo keeps
the finding and not just the patch.

Reviewer bias worth stating: the first pass was done by the same author who
wrote the code. A second, independent review was commissioned for the areas
not covered below.

---

## Confirmed defects

### A1 — `stale` and `failing` are not independent (high)

**`atlas/pipeline/freshness.py`, `classify()`**

The README states that ATLAS distinguishes two failure modes: `failing`
(ATLAS could not fetch — our problem) and `stale` (the source has not
published — not our problem). The schema has a `last_source_publication`
column for exactly this.

`classify()` never reads it. Its only inputs are `expected_frequency`,
`last_successful` and `consecutive_failures`. `stale` is therefore derived
from how long ago ATLAS last *fetched successfully* — which is still a fact
about ATLAS, not about the source.

**Failure scenario.** The pipeline runs daily and succeeds every time, but
World Bank has published nothing new since 2024. Status reports `current`.
A consumer trusting `/status` sees a healthy source serving two-year-old
figures.

### A2 — the test asserting A1 is false assurance (high)

**`tests/test_pipeline.py`, `test_failure_and_staleness_are_different_states`**

The test passes. Its inline comment reads *"We fetched fine; the source
simply hasn't published"* — but the assertion beneath sets
`last_successful = now - 30 days`, which means ATLAS did **not** fetch fine.

The test encodes the exact conflation it claims to rule out, and is green.
Worse than no test: the name and the passing status together assert a
property the system does not have.

### A3 — `standardise_pending` discards committed work and reports success (high)

**`atlas/pipeline/standardise.py`, `standardise_pending()`**

The per-artifact `except` calls `conn.rollback()`, which rolls back the
entire open transaction rather than the failed artifact.

**Failure scenario.** Three unparsed artifacts. Artifacts 1 and 2 parse and
write observations; artifact 3 raises. The rollback discards all three.
`report.artifacts_read` and `report.rows_written` still count 1 and 2, so
the run prints `parsed 2 artifact(s) -> 500 observation(s)` having committed
nothing.

The comment in that block — *"Nothing is lost and nothing half-written is
committed"* — is false. Needs a savepoint per artifact
(`with conn.transaction():`).

### A4 — no currency model (medium, blocking for multi-country)

**`migrations/004_indicators.sql`**

`unit` is free text. There is no currency code, no FX rate table, and
nothing that prevents an indicator denominated in KES being compared,
ranked or aggregated alongside one in UGX.

Harmless while every indicator is USD. Breaks the first time a national
statistics office supplies local currency — which is the normal case for
four of the five target countries.

### A5 — historical boundaries modelled but never populated (medium)

`place.valid_from` / `valid_to` exist and are always NULL. Uganda's
districts have split repeatedly; a time series across a split will silently
mix incompatible areas. Kenya-only rollout hides this.

## Test coverage gaps

Measured by symbol references across `tests/`:

| Symbol | References in tests |
| --- | --- |
| `fail_chunk` | 0 |
| `AcquisitionStatus` / `PARTIAL` | 0 |
| `failed_chunks` | 0 |
| `artifacts_failed` | 0 |

The resumable-acquisition design — described in the README as the thing that
makes a failed backfill cost one chunk rather than the whole run — has no
test coverage at all. A3 survived 36 passing tests for this reason.

## Claims to correct in README

- **S3 backend.** Written, never run against a real bucket. The status table
  says so; Known Limitations does not, and the Dockerfile ships
  `ATLAS_STORAGE_BACKEND=local` to a platform with no persistent disk.
  No production S3 capability should be claimed.
- **Five-country support.** True at the schema level only. Country-specific
  identifiers, boundary levels, currencies and ingestion behaviour are
  untested beyond Kenya.
