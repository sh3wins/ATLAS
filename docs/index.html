Known limitations

  • This page is a snapshot, not a live API. The freshness states below describe the pipeline at the moment of export.
  • One sample point per county. Each county's rainfall is read from a single ERA5-Land cell. Turkana spans roughly 567 such cells and Wajir 461, so these are point readings labelled with a county name, not area averages.
  • Values are modelled, not measured. ERA5 is a reanalysis that assimilates observations; it is not a rain gauge.
  • S3 is written but unverified against a real bucket.
  • Five countries are supported in the schema; only Kenya has data. Uganda, Tanzania, Rwanda and Burundi are architecture, not coverage.
